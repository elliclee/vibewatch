# App 图标

当前母版为 [app-icon-source.png](app-icon-source.png)，采用用户选定的 A「蓝紫曲面」方案，由内置 imagegen 工具生成。蓝紫色柔软曲面、细腻光泽与浅色留白，用于 iPhone 与 Watch。没有文字或预制外部圆角，由系统应用图标遮罩。

在仓库根目录运行 `swift scripts/generate_app_icons.swift`，从已确认母版生成两个目标的 1024 × 1024 sRGB、无透明通道 PNG。脚本不调用生成服务，不需要密钥。
