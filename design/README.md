# App 图标

当前母版为 [app-icon-source.png](app-icon-source.png)，由内置 imagegen 工具生成。朱红背景、暖白几何 V 字与斜切口，用于 iPhone 方形和 Watch 圆形系统遮罩。未预制外部圆角。

在仓库根目录运行 `swift scripts/generate_app_icons.swift`，可从母版生成两个目标的 1024 × 1024 sRGB、无透明通道 PNG。脚本不调用生成服务，不需要密钥。
