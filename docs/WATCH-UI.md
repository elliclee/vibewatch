# Watch 界面

当前界面采用额度与用量两页，详见 [WATCH-DASHBOARD.md](WATCH-DASHBOARD.md)。Watch App 不显示大号 VibeWatch 导航标题，保留系统时间和主体信息层级。

额度页仅显示实际窗口，缺失百分比使用 —，不推断无限。重置卡片与采集时间区分未来重置、待更新和缓存过期。小屏可滚动，刷新按钮位于内容下方。

表盘组件仍为矩形与圆形：矩形按实际窗口显示，圆形优先主窗口，主窗口缺失时使用同 bucket 次窗口并标识时长。点击打开 Watch App。

布局根据界面需求独立实现。预览由 SwiftUI 源码渲染，不使用真实账号数据。

额度名称统一将 `codex` 显示为 `Codex`，适用于 App 和组件；协议标识与已保存的 bucket 选择不变。
