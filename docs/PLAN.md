# 项目状态与路线图

## 当前基线

0.1.0，内部验证构建 8。默认三目标：iPhone App、Watch App、Watch 表盘组件。已完成真实额度采集、Workers/D1 同步、一次性配对、Watch 两页布局、本机用量统计及离线状态。已有内部 TestFlight 分发验证，但开源使用者需要自己的云端与签名账号。

## 开源发布整理

- MIT 许可，中文 README、部署、构建、架构与贡献说明。
- 移除个人部署 ID、认证默认值、历史操作记录；私有材料留在忽略目录。
- 提供个人 XcodeGen 配置生成器、可配置的三目标签名脚本。
- 干净检出验证 Python、云端、Swift 模型和 Apple SDK 构建，添加 CI。

## 后续工作

- iPhone 桌面/锁屏小组件：已有实验源码，默认不构建；需要手机 App Group、四目标签名与升级迁移实机验证。
- 验证不同 Watch 尺寸、动态字号、Always On、减少动态效果与长时间系统组件调度。
- 验证 Mac 休眠唤醒、网络中断、撤销设备与切换账号的长时间行为。
- 扩充 Codex 接口变化的兼容性测试。

## 工程原则

业务代码独立实现，不引入许可不兼容的第三方源码或素材。缺失数据显示未知，不推断无限或满额；没有明文凭据兜底。复杂开发先补简短方案，新增关键行为测试，完成后同步公开运行说明。

本项目暂不计划在第一版引入多租户、APNs 推送、自定义系统表盘或通知系统。
